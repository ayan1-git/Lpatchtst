# Plan: Archive v1 Feature Pipeline, Ship New 10-Feature Set

## Goal

Replace the current 20-feature engineering pipeline with a minimal 10-feature close-only set. Archive (never delete) the old feature code and `talib_features.py`. Keep the target column for training.

## Confirmed Decisions

| Decision | Value |
|---|---|
| Feature families | 4: raw log return, vol-normalized returns, log EWMA vol, vol-normalized momentum |
| Column count | 10 model inputs + 1 training-only target |
| Horizons | ret_norm: **(1, 5, 20)**; momentum: **(3, 10, 40)** — staggered to avoid redundancy |
| Momentum formula | Same as vol-normalized return: `r(t,h) / (σ_t·√h)` |
| EWMA vol | `log(σ)` at spans **10, 20, 60** → `log_ewma_vol_10/20/60` |
| Normalization σ | Span **60** (most stable of the three) used consistently as denominator σ_t in ret_norm, mom_norm, and target; configurable via `vol_norm_span` |
| Target column | **Keep** `target_norm_ret = clip(r_{t+1}/σ_t, ±20)` with inference-mode RuntimeError guard (training label, never built at inference) |
| File layout | In-place swap: old files → `core/archive/`, new file at `core/features.py` so existing imports keep working |
| OHLC features | Dropped entirely (KER, ICP, RSI, vol asymmetry, local structure, session sin/cos, vol squeeze, MACD) |
| talib_features.py | Archived, no longer referenced |
| Tokenizer | Out of scope — pipeline runs `INPUT_MODE="features_only"`; tokenizer excluded per user |

## Exact New Output Schema (in build order)

```
log_ret_1          1-bar log return                          NO_SCALE
ret_norm_1         r(t,1)/(σ60·√1)                           NO_SCALE
ret_norm_5         r(t,5)/(σ60·√5)                           NO_SCALE
ret_norm_20        r(t,20)/(σ60·√20)                         NO_SCALE
log_ewma_vol_10    log(EWMA vol, span=10)                    NO_SCALE
log_ewma_vol_20    log(EWMA vol, span=20)                    NO_SCALE
log_ewma_vol_60    log(EWMA vol, span=60)                    NO_SCALE
mom_norm_3         r(t,3)/(σ60·√3)                           NO_SCALE
mom_norm_10        r(t,10)/(σ60·√10)                         NO_SCALE
mom_norm_40        r(t,40)/(σ60·√40)                         NO_SCALE
target_norm_ret    clip(r_{t+1}/σ60, ±20)   [include_target only]
```

All 10 features are ≈z-scored by construction → every one goes to the NO_SCALE bucket. ROBUST bucket becomes empty (still supported by the scaler).

## Risks / Failure Modes

- **Column-order drift between train/inference**: mitigated by deriving `_build_feature_cols` from the same config fields and matching build() order exactly.
- **Unknown-column default is ROBUST** in `_col_bucket`: any missed rename silently gets RobustScaler instead of passthrough. Mitigated by explicit prefix rules + smoke test asserting bucket assignment per column.
- **Checkpoint incompatibility**: any previously trained model expects 20-feature input dim; a fresh training run is required after this change (expected and intended).
- **cudf.pandas pitfalls**: reuse the archived numpy-escape implementations verbatim rather than writing fresh pandas code.
