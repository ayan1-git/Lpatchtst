# Plan: Convert PatchTST from Decoder-Only to Encoder-Decoder Architecture

## 1. Current Architecture Analysis

### What exists now (`model.py`)
- **`InputStem`**: Multi-modal input handler (tokens/features/combined) → `(B, L, d_model)`
- **`PatchTST`**: Decoder-only causal transformer
  - InputStem → Positional Embedding → LSTM (optional) → **Causal TransformerEncoder** (with `torch.triu` mask) → Aggregation Head → `tanh`
  - Uses `nn.TransformerEncoder` with a causal (upper-triangular) mask — every position only attends to itself and prior positions
  - The head does global average pooling over time → Linear → tanh for regression
- **`LPatchTST`**: Subclass of PatchTST with different defaults (combined mode, smaller patch_len/stride)

### Key observations
- The model is a **regression** model (not autoregressive generation): it takes a lookback window and outputs a single scalar prediction
- The causal mask is the defining characteristic of "decoder-only" — it prevents future positions from attending to past ones
- The current architecture has no concept of a separate decoder or cross-attention
- `train.py`, `evaluate.py`, `inference.py` all call `model(tokens=..., features=...)` and expect a single scalar output per sample
- The `_is_head()` function in `train.py` classifies parameters into head vs encoder groups for differential learning rates — this must continue to work

## 2. Encoder-Decoder Architecture Design

### 2.1 High-Level Concept

The encoder-decoder architecture separates the model into two stages:

1. **Encoder**: Processes the full lookback window with **bidirectional** self-attention (no causal mask). This builds a rich, context-aware representation of the entire input sequence — every position can attend to every other position.

2. **Decoder**: Takes the encoder's output and produces the prediction. For a regression task (single scalar output), the decoder is a lightweight cross-attention + pooling head that "queries" the encoded representation.

### 2.2 Why Encoder-Decoder for This Task

- **Bidirectional context**: The encoder can use both past AND future context within the lookback window. In financial time series, patterns often have symmetric context (e.g., a support level is meaningful relative to both prior and subsequent bars within the window).
- **Cleaner separation of concerns**: Feature extraction (encoder) is decoupled from prediction (decoder).
- **Cross-attention mechanism**: The decoder learns which parts of the encoded sequence are most relevant for the prediction, providing implicit interpretability.
- **Proven in literature**: T5, original Transformer (Vaswani et al.), and modern time-series models (Informer, Autoformer) all use encoder-decoder for forecasting.

## 3. Implementation Plan

### 3.1 New Components to Add in `model.py`

#### 3.1.1 `FeedForward` (SwiGLU) — Replace existing ReLU/SiLU FFN
- **Current**: `nn.TransformerEncoderLayer` uses PyTorch default (Linear → ReLU → Linear)
- **New**: `FeedForward(d_model, dim_feedforward)` with `SiLU` activation: `w2(SiLU(w1(x)) * w3(x))` (gated linear unit, matching LLaMA/Kronos style)
- **Why**: Better gradient flow, standard in modern architectures

#### 3.1.2 `EncoderLayer` — Bidirectional self-attention block
```python
class EncoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, dim_feedforward, dropout):
        self.norm1 = nn.LayerNorm(d_model)
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout, batch_first=True)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = FeedForward(d_model, dim_feedforward)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x):
        # Pre-LN: norm → attn → residual
        x = x + self.dropout(self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x))[0])
        x = x + self.ffn(self.norm2(x))
        return x
```
- **No causal mask** — full bidirectional attention
- Pre-LayerNorm (matching current `norm_first=True`)

#### 3.1.3 `DecoderLayer` — Causal self-attention + cross-attention
```python
class DecoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, dim_feedforward, dropout):
        self.norm1 = nn.LayerNorm(d_model)
        self.self_attn = nn.MultiheadAttention(d_model, n_heads, dropout, batch_first=True)
        self.norm2 = nn.LayerNorm(d_model)
        self.cross_attn = nn.MultiheadAttention(d_model, n_heads, dropout, batch_first=True)
        self.norm3 = nn.LayerNorm(d_model)
        self.ffn = FeedForward(d_model, dim_feedforward)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, enc_output, self_attn_mask=None):
        # Causal self-attention on queries
        x = x + self.dropout(self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), attn_mask=self_attn_mask)[0])
        # Cross-attention: queries attend to encoder memory
        x = x + self.dropout(self.cross_attn(self.norm2(x), enc_output, enc_output)[0])
        # FFN
        x = x + self.ffn(self.norm3(x))
        return x
```

#### 3.1.4 `PredictionHead` — Decoder output → scalar
```python
class PredictionHead(nn.Module):
    def __init__(self, d_model, dropout):
        self.pool = "mean"  # or "cls"
        self.net = nn.Sequential(
            nn.Linear(d_model, d_model // 2),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_model // 2, 1),
        )
    
    def forward(self, decoder_output):
        # decoder_output: (B, K, d_model)
        if self.pool == "mean":
            x = decoder_output.mean(dim=1)  # (B, d_model)
        else:  # CLS
            x = decoder_output[:, 0]  # (B, d_model)
        return torch.tanh(self.net(x))  # (B, 1)
```

### 3.2 Modified `PatchTST` Class

Replace the current `nn.TransformerEncoder` + causal mask with:

```python
class PatchTST(nn.Module):
    def __init__(self, ..., n_dec_layers=1, n_queries=4, ...):
        # ... (input stem, pos embedding, LSTM unchanged)
        
        # ENCODER: bidirectional
        self.encoder_layers = nn.ModuleList([
            EncoderLayer(d_model, n_heads, d_model * 2, dropout)
            for _ in range(n_layers)
        ])
        self.encoder_norm = nn.LayerNorm(d_model)
        
        # DECODER
        self.n_queries = n_queries
        self.query_embed = nn.Embedding(n_queries, d_model)  # learnable queries
        self.decoder_layers = nn.ModuleList([
            DecoderLayer(d_model, n_heads, d_model * 2, dropout)
            for _ in range(n_dec_layers)
        ])
        self.decoder_norm = nn.LayerNorm(d_model)
        
        # HEAD
        self.head = PredictionHead(d_model, dropout)
    
    def forward(self, tokens=None, features=None):
        # Steps 1-3: stem → pos embed → LSTM (unchanged)
        x = self.input_stem(...)
        x = x + pos_embedding
        x = self.dropout(x)
        if self.lstm: x, _ = self.lstm(x)
        
        # Step 4a: ENCODER (bidirectional, no mask)
        for layer in self.encoder_layers:
            layer(x)
        enc_output = self.encoder_norm(x)  # (B, L, d_model)
        
        # Step 4b: DECODER
        # Expand learnable queries for this batch
        queries = self.query_embed.weight.unsqueeze(0).expand(B, -1, -1)  # (B, K, d_model)
        # Causal mask for self-attention on queries (K x K)
        dec_self_mask = torch.triu(torch.ones(K, K, device=x.device), diagonal=1).bool()
        for layer in self.decoder_layers:
            queries = layer(queries, enc_output, self_attn_mask=dec_self_mask)
        dec_output = self.decoder_norm(queries)  # (B, K, d_model)
        
        # Step 5: HEAD
        return self.head(dec_output)  # (B, 1)
```

### 3.4 Backward Compatibility Considerations

**Checkpoint loading**: The new architecture has completely different parameter names (encoder_layers, decoder_layers, query_embed, etc.) vs the old one (encoder, enc_dropout). Old checkpoints will NOT load directly. This is acceptable because:
- The `_build_model()` function in `train.py` creates a fresh model
- Old checkpoints can be loaded with `strict=False` for partial weight transfer if desired
- The `_is_head()` function in `train.py` needs updating to recognize new decoder/encoder parameter names

**Aggregation mode**: The current code supports `"mixing"` and `"mean"` aggregation. The new architecture always uses the `PredictionHead` (equivalent to `"mixing"`). The `"mean"` mode (flatten → Linear) should be kept as a legacy option or removed since the new head subsumes it.

### 3.5 `_is_head()` Update in `train.py`

The head vs encoder parameter split for differential learning rates needs to include decoder parameters:

```python
_HEAD_PREFIXES = (
    "head", "fc", "proj", "output", "feature_head",
    "regressor", "out_layer", "prediction_head", "linear_head",
    "decoder", "query_embed",  # NEW: decoder params trained with head LR
)
```

Wait — actually, the decoder should be trained with the encoder LR (low), not the head LR (high). Let me reconsider:

- **Encoder params**: Low LR (frozen in stage A, very low LR in stage B)
- **Decoder params**: Medium LR (these are new, need to learn cross-attention)
- **Head params**: High LR (task-specific)

For simplicity, group decoder with encoder (both low LR). The `_is_head()` function should NOT match "decoder" or "query_embed".

## 5. Hyperparameter Defaults

| Parameter | Default | Rationale |
|-----------|---------|-----------|
| `n_dec_layers` | 1 | Single decoder layer sufficient for regression (queries → cross-attn → FFN) |
| `n_queries` | 4 | Multiple queries let the decoder attend to different aspects of the encoded sequence; 4 is a good balance |
| Encoder `dim_feedforward` | `d_model * 2` | Matches current `d_model * 2` in `TransformerEncoderLayer` |
| Decoder `dim_feedforward` | `d_model * 2` | Same as encoder |

## 7. Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Old checkpoints incompatible | Expected; new architecture = retrain from scratch |
| Decoder doesn't converge | Start with `n_dec_layers=1`, `n_queries=4`; increase if underfitting |
| Memory increase from cross-attention | Cross-attn is O(K×L) where K=4 queries, L=512 — negligible |
| `_is_head()` misclassifies decoder params | Decoder params grouped with encoder (low LR) — safe default |
| `torch.compile` issues with new modules | Test early; all modules use standard PyTorch ops |
